Answers to Questions

  1. What segments must be lit?
    Letter Segments Byte
    S gfdca 0b01101101
    H gfecb 0b01110110
    E gfeda 0b01111001
  2. What byte do I need to send?
    • See the table above.
  3. What mode do I have to set?
    • Mode 0, because all I need are the outputs
  4. Can I modify the 8255 to support a nine-digit display?
    • Yes. One of the bits in port B is unused, so I could just use that for the ninth digit.
    • Alternatively, I could use a bit from port C for the same purpose.
    • Both of these options would require a little bit of extra circuitry, though.

Some other questions

  1. Control Word Setup: The control word 0x80 sets all ports to output, puts them in Mode 0 (basic I/O), and enables them
  2. SSD bit pattern: look at Table B in the lab document. It's really straight forward.
  3. Port A: since outputs are latched in Mode 0 on the 8255, we can just write the relevant byte to port A to activate our desired output digit, and then write a byte to port B to display the letter that we want.
    • Sidenote: the diagram in the lab doc is borked. All of NPN transistors for port A have their emitters connected to VCC. So current can't actually flow through it.
  4. Schmovement: I used a look-up table for the SSD, along with an indexing offset to determine which parts should be written. For the timing, I'm just using normal Linux syscalls. 201 is the syscall for system time (unix epoch), in seconds.
  5. Code description: it should be very self-explanatory from the comments, but if you have any questions feel free to shoot me an email.
