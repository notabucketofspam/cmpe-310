A brief explanation of the circuit

  • pin 13 is connected to one of the LEDs
  • pin 12 is connected to a different LED
  • They're both tied to the same ground

Explaining the code

  • There's a global variable for the current time
  • There's another global variable to keep track of state
  • set pin 13 and pin 12 to be outputs (i.e., DDB |= ((_BV(4))|(_BV(5))))
  • if 2/3 of a second have passed...
    • increase the state variable
    • set the output of pin 13 based on the state
    • set the output of pin 12 to be 1/2 of the state (i.e., it's a clock divider)
