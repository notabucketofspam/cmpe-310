# lab 4

## How to run this lab

```
./runme
```

note: you may need to `chmod +x runme` first. or, you can do `. runme`.

if you want to run it with different `data.txt` files:
```
./lab4 my_cool_data_file.txt
```

there's also a `verify.js` file that you can run with nodejs, if you want to make sure that the math works out ok.
