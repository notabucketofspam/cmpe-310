# lab 1 (one)

## how to run the stuff in this lab

you can do something like this:
```bash
. run_tN
```
where `N` is the *task number*.

so, for example: `. run_t1` shall run task 1.

---

## why is there whitespace in my run command?

what's with the space in the middle? why not have it be `./run_tN`?

- it's because I didn't feel like `chmod +x`ing all of the `run_tN` files.
- you can do `chmod +x run_tN` and then `./run_tN`, if that's more your speed.
